Deux versions, HTML en styles en ligne (aucune feuille de style, aucun script) : compatible Gmail web et Outlook.com / Outlook web.
Two versions, all-inline HTML, no CSS file and no script — works in Gmail web and Outlook.com.

Gmail web

  1. Cliquez sur Copier la signature, puis collez dans Gmail. Click Copy signature, then paste into Gmail.
  2. Gmail → ⚙ Voir tous les paramètres → Général → Signature → Créer. Gmail → Settings → General → Signature → Create new.
  3. Collez avec Ctrl + V dans la zone, sélectionnez la signature créée, puis Enregistrer les modifications en bas de page. Paste with Ctrl + V, then click Save changes at the bottom.
  4. Optionnel : cochez la signature par défaut pour « Répondre / Transférer ». Optionally set it as default for replies and forwards.

Outlook.com / Outlook web

  1. Cliquez sur Copier la signature. Click Copy signature.
  2. Outlook → ⚙ Paramètres → Courrier → Composition et réponse. Outlook → Settings → Mail → Compose and reply.
  3. Collez avec Ctrl + V dans la zone Signature. Paste with Ctrl + V into the Signature box.
  4. Choisissez la signature par défaut pour les nouveaux messages et les réponses, puis Enregistrer. Pick it as the default for new messages and replies, then Save.
